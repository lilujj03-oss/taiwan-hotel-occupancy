# Power BI DAX 量值公式

這份對應 `powerbi_匯入資料_1130.xlsx` 裡新增的**列層級原始表 `旅館月度原始資料`**（4,832 列，一列＝一間旅館一個月）。跟其他 17 個分頁不同——那些是 Python 已經算好的**靜態結果**；這張表是**原始資料**，配合下面的 DAX 量值，可以在 Power BI 裡隨篩選器（年度、縣市、星等、聚落…）動態重算，不是寫死的數字。

## ⚠️ 一定要注意的口徑陷阱：2023-2025 主分析 vs 2026 盲測期
`旅館月度原始資料` 涵蓋 2023-01 到 2026-06 全部 4,832 筆，但簡報的所有結構性結論（季節擺盪、星等差距、縣市營收佔比…）都**只用 2023-2025 主分析範圍算的（4,138 筆）**——2026 上半年是刻意保留給模型盲測，沒有放進這些分析。

**我第一次寫這份文件時漏掉這個篩選，直接在全部 4,832 筆上驗算，結果數字對不上簡報**（都會擺盪算出 12.45、簡報是 14.2；星等差距算出 16.34、簡報是 16.78）。加上篩選後重算，全部精確吻合（都會擺盪 14.23≈14.2、星等差距 16.78、台北營收佔比 50.2%）。

所以表裡多了一欄 **`資料範圍`**（值為「主分析(2023-2025)」或「盲測期(2026)」），下面所有量值都已經**內建這個篩選**，不用你自己記得每次手動加。

## 建置步驟
1. 匯入 `旅館月度原始資料` 分頁後，在 Power BI「模型」檢視裡，新增一個量值資料表（可以是空白的，右鍵「新增量值」）。
2. 把下面每一條貼進「新增量值」的公式列。
3. 量值建好後，拖進視覺效果就會自動隨篩選器重算——例如拉「聚落」當篩選器，`[加權住房率]` 就會分別顯示都會/度假各自的數字，且自動排除 2026 盲測期資料。

---

## 基礎量值（加權 vs 簡單平均，已內建 2023-2025 篩選）

```dax
加權住房率 =
CALCULATE(
    DIVIDE(
        SUM('旅館月度原始資料'[已售房晚]),
        SUM('旅館月度原始資料'[可售房晚])
    ) * 100,
    '旅館月度原始資料'[資料範圍] = "主分析(2023-2025)"
)
```

```dax
加權ADR =
CALCULATE(
    DIVIDE(
        SUM('旅館月度原始資料'[客房營收]),
        SUM('旅館月度原始資料'[已售房晚])
    ),
    '旅館月度原始資料'[資料範圍] = "主分析(2023-2025)"
)
```

```dax
加權RevPAR =
CALCULATE(
    DIVIDE(
        SUM('旅館月度原始資料'[客房營收]),
        SUM('旅館月度原始資料'[可售房晚])
    ),
    '旅館月度原始資料'[資料範圍] = "主分析(2023-2025)"
)
```

```dax
簡單平均住房率 =
CALCULATE(
    AVERAGE('旅館月度原始資料'[住房率]),
    '旅館月度原始資料'[資料範圍] = "主分析(2023-2025)"
)
```

```dax
簡單平均ADR =
CALCULATE(
    AVERAGE('旅館月度原始資料'[平均房價]),
    '旅館月度原始資料'[資料範圍] = "主分析(2023-2025)"
)
```

**口徑提醒**（呼應簡報第 5 頁）：加權＝總量相除（大旅館分量重）；簡單平均＝每「旅館×月」各算一票。兩者在篩選器下都會各自正確重算，但意義不同，別混用來比較。

如果你想改看 2026 上半年盲測期的實際表現（不是模型預測，是真實住房率），把上面每條的 `"主分析(2023-2025)"` 換成 `"盲測期(2026)"` 即可。

## 年度變化量值

```dax
前一年加權住房率 =
CALCULATE(
    [加權住房率],
    FILTER(
        ALL('旅館月度原始資料'[年]),
        '旅館月度原始資料'[年] = MAX('旅館月度原始資料'[年]) - 1
    )
)
```

```dax
住房率年增(pp) = [加權住房率] - [前一年加權住房率]
```

用法：把「年」放在切片器或篩選器，`[住房率年增(pp)]` 會自動算出「今年 vs 去年」的差距（對應第 6 頁「2023→2025」欄的邏輯，只是變成逐年動態版）。

---

## 淡旺季擺盪（第 8 頁的邏輯）

```dax
月度住房率擺盪 =
CALCULATE(
    VAR MonthlyAvg =
        SUMMARIZE(
            '旅館月度原始資料',
            '旅館月度原始資料'[月],
            "月均值", AVERAGE('旅館月度原始資料'[住房率])
        )
    RETURN
        MAXX(MonthlyAvg, [月均值]) - MINX(MonthlyAvg, [月均值]),
    '旅館月度原始資料'[資料範圍] = "主分析(2023-2025)"
)
```

用法：拉「聚落」當篩選器，分別看都會（應算出 14.2）跟度假（9.4）的擺盪值，已驗證跟簡報第 8 頁簡單平均口徑數字精確吻合。

## 星等溢價（第 14 頁的邏輯，只算原始差距，OLS 控制後的 12.15pp 沒辦法在 DAX 重算）

```dax
有星等住房率 =
CALCULATE(
    [簡單平均住房率],
    '旅館月度原始資料'[有星等] = 1
)
```

```dax
無星等住房率 =
CALCULATE(
    [簡單平均住房率],
    '旅館月度原始資料'[有星等] = 0
)
```

```dax
星等原始差距(pp) = [有星等住房率] - [無星等住房率]
```

（`[簡單平均住房率]` 已經內建 2023-2025 篩選，這三條不用再另外加一次。已驗證：差距算出 16.78pp，跟簡報左卡完全一致。）

**限制要講清楚**：這三條只能重現第 14 頁左卡「表象」的原始差距，右卡「控制後仍有 12 pp」是跑了迴歸控制縣市/房數/月份/客源、加上 600 次 cluster bootstrap 才算出來的——DAX 沒有迴歸引擎，這個數字沒辦法在 Power BI 裡重算，只能用 `星等OLS控制分析` 分頁的靜態結果做卡片展示。

## 縣市/聚落佔比

```dax
營收佔全體比例 =
CALCULATE(
    DIVIDE(
        SUM('旅館月度原始資料'[總營收]),
        CALCULATE(SUM('旅館月度原始資料'[總營收]), ALL('旅館月度原始資料'[縣市]))
    ) * 100,
    '旅館月度原始資料'[資料範圍] = "主分析(2023-2025)"
)
```

用法：拉「縣市」到表格或長條圖的軸上，這條量值會自動算出每個縣市佔全體的營收百分比（已驗證台北市算出 50.2%，跟簡報第 10 頁一致）。

## 樣本數（呼應圖表 X 軸標籤裡的「(N 間)」）

```dax
旅館家數 =
CALCULATE(
    DISTINCTCOUNT('旅館月度原始資料'[旅館名稱]),
    '旅館月度原始資料'[資料範圍] = "主分析(2023-2025)"
)
```

## 這張表沒辦法重算的東西（維持用靜態分頁）
模型 MAE／RMSE／R²、特徵重要性、期程衰減、OLS 信賴區間——這些全部是 Python 的 scikit-learn 模型跑出來的結果，不是從 `旅館月度原始資料` 直接加總能得到的數字，Power BI 沒有等效的機器學習運算引擎。這幾張圖請直接用 `候選模型比較`、`期程衰減`、`特徵重要性`、`星等OLS控制分析` 這幾個靜態分頁展示，不用嘗試在 DAX 裡重現。
