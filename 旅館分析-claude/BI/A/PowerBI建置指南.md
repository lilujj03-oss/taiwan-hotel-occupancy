# Power BI 圖表建置指南

## 為什麼沒有直接給 .pbix 檔
Power BI 檔案（.pbix）是微軟的專屬二進位格式，沒有 Python 套件能像產生 .pptx 那樣直接寫出來，我這邊也沒有 Power BI Desktop 可以操作、驗證。這份指南搭配 `powerbi_匯入資料_1130.xlsx`，讓你在 Power BI Desktop 裡幾分鐘內重建每一張圖。

## 開始前：匯入資料
1. 打開 Power BI Desktop → 常用 → **取得資料 → Excel活頁簿**
2. 選 `powerbi_匯入資料_1130.xlsx`，18 個分頁全部勾選匯入
3. 每個分頁會變成一張獨立的表，欄位名稱都已經是中文、乾淨可直接用

## 建議的頁面（報表分頁）分組
把 Power BI 報表分成幾頁，對應原簡報的 PART 結構：
- **頁1 營運總覽**：圖 1、2（年度大表、指數化）
- **頁2 結構分析**：圖 3、4、5、6（季節、聚落、縣市、客源）
- **頁3 星等分析**：圖 7、8、9（階梯、三視角、OLS）
- **頁4 資料特性**：圖 10、11（房價/規模非線性、陸客體制）
- **頁5 模型效能**：圖 12、13、14、15（多基準、模型比較、期程衰減、特徵重要性）
- **頁6 穩健性**：圖 16（縣市誤差）

## 顏色建議（對齊原簡報色碼）
- 藍 `#2546C7`（主色）、青 `#0E8B7B`（第二資料色）、琥珀 `#BE730A`（注意色）、紅 `#C1334E`（限制/警語）、灰 `#A6AEBB`（對照）
- 在 Power BI「格式」→「資料顏色」逐一設定十六進位色碼，可讓報表跟原簡報視覺一致

## 有一個地方 Power BI 做不到
第 14 頁的 cluster bootstrap 信賴區間（95% CI 1.81–21.3 pp）是 Python 統計運算的結果，不是 Power BI 內建的視覺效果能重算的——`星等OLS控制分析` 分頁已經把算好的數字匯出，Power BI 只能「展示」這個結果（卡片視覺效果 + 文字說明），沒辦法在 Power BI 裡重跑這個迴歸分析。
